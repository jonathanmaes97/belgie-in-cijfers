À propos de ce site

Chacun peut débattre et voter sur les politiques publiques. Pour cela, il faut des chiffres, et ils sont souvent cachés dans des tableaux, des rapports et du jargon. Ce site rassemble les principaux chiffres officiels sur la Belgique, les explique en langage clair et indique pour chaque chiffre d'où il vient. Les chiffres disent ce qui est ; ce que vous en pensez, c'est à vous de le décider.

Comment ça marche ?

Chaque jour, un programme récupère automatiquement les chiffres auprès des sources officielles, les vérifie et reconstruit le site. Personne ne recopie de chiffres à la main, et aucune IA n'intervient dans les chiffres eux-mêmes. Certains chiffres sont calculés par nos soins à partir de chiffres officiels, comme la dette par habitant ; la formule et la source de chaque élément sont alors indiquées. Si une source révise un chiffre, nous reprenons la nouvelle version et gardons la trace de la révision. Si la récupération échoue un jour, le dernier chiffre valide reste affiché, avec une mention.

Neutre

Le site ne porte pas de jugement. Des phrases comme « plus élevé que la moyenne de l'UE » sont calculées à partir des données et ne font que comparer. Les couleurs servent uniquement à reconnaître les thèmes ou à montrer une norme ou un objectif officiel. Vous pouvez afficher les gouvernements fédéraux sur les graphiques, avec l'avertissement qu'un gouvernement n'est jamais la seule cause de l'évolution d'un chiffre.

Vie privée

Ce site n'utilise pas de cookies et ne collecte pas de données personnelles. Le simulateur calcule dans votre propre navigateur : ce que vous saisissez n'est envoyé nulle part. Si vous affichez les gouvernements sur les graphiques, ce choix est retenu uniquement dans votre propre navigateur. Pour savoir combien de personnes visitent le site, nous comptons les visites avec GoatCounter : sans cookies, sans vous suivre sur d'autres sites et sans conserver de données personnelles.

Construit avec l'IA

Le code et les textes de ce site ont été écrits avec l'aide de Claude, une IA d'Anthropic. Pas les chiffres : ils proviennent directement et automatiquement des sources. Tout le code est public, pour que chacun puisse vérifier comment cela fonctionne.
